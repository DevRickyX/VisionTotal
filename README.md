# Visión Total — nueva web

Primera landing accesible y responsive construida con Next.js 16, React 19, TypeScript y Tailwind CSS 4.

## Ejecutar localmente

```bash
pnpm install
pnpm dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Comprobar producción

```bash
pnpm lint
pnpm build
```

La comparación de CMS, los costos, la arquitectura y las decisiones están en [TECHNICAL_PROPOSAL.md](TECHNICAL_PROPOSAL.md).
